# Story Outputs

This folder stores the generated outputs for each completed story.

## Naming Convention

| File | Pattern |
|------|---------|
| Test Cases | `US-NNN_test_cases.md` |
| Risk Analysis | `US-NNN_risk_analysis.md` |
| Execution Summary | `US-NNN_execution_summary.md` |

## How to Save Outputs for a Story

After running all three skills for a story, copy the output files here:

```
outputs/generated_test_cases.md   →   stories/outputs/US-NNN_test_cases.md
outputs/risk_analysis.md          →   stories/outputs/US-NNN_risk_analysis.md
outputs/execution_summary.md      →   stories/outputs/US-NNN_execution_summary.md
```

Then update the story's status in `stories/story_index.md` to ✅ Complete.
