## Recommended Focus Areas

1. **Token security** — Expiry at 30 min (boundary), single-use enforcement, invalidation on new request
2. **Password history enforcement** — Reuse of last 3 passwords rejected; 4th-previous password accepted
3. **Lockout-reset integration** — Account unlocks only after new password is successfully saved
4. **Email enumeration prevention** — Unregistered email returns same generic response as registered email
5. **Post-reset MFA** — First login after reset must trigger MFA (OTP)

---

## Mitigation Suggestions

- Enforce single-use tokens at the API level — invalidate immediately on first use
- Use constant-time comparison for token validation to prevent timing attacks
- Apply rate limiting on the reset request endpoint (not in ACs — recommend adding)
- Log all password reset events (request, success, failure) to the audit trail
- Ensure SMTP failure is handled gracefully — do not expose internal errors to the user
